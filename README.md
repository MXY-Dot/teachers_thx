# teachers_thx

3D-открытка с благодарностью учителям английского: конверт открывается, письмо выплывает с параллаксом, падают лепестки, играет тихая музыка.

**Сайт:** https://mxy-dot.github.io/teachers_thx/

Открытка рассчитана на очень медленный интернет: вся страница с шрифтами — около 75 КБ в сжатом виде, без внешних запросов. Музыка и звуки бумаги генерируются в браузере через Web Audio. После первого визита сервис-воркер (`sw.js`) держит всё в кеше, и открытка открывается без интернета.

Чтобы посмотреть локально, достаточно открыть `index.html` в браузере.

**Если меняете текст** заголовка, листка в конверте или подписи, пересоберите шрифты, иначе новые буквы покажутся запасным шрифтом:

```
node scripts/subset-fonts.mjs
```

Деплой: каждый пуш в `main` минифицирует страницу и публикует её через GitHub Actions (`.github/workflows/pages.yml`).
