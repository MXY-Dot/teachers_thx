# teachers_thx

3D-открытка с благодарностью учителям английского: конверт открывается, письмо выплывает с параллаксом, падают лепестки, играет тихая музыка.

**Сайт:** https://mxy-dot.github.io/teachers_thx/

Вся открытка — один файл `index.html`, без сборки и зависимостей (кроме шрифтов Google Fonts). Музыка и звуки бумаги генерируются в браузере через Web Audio, поэтому страница весит меньше 50 КБ.

Чтобы посмотреть локально, достаточно открыть `index.html` в браузере.

Деплой: каждый пуш в `main` публикует сайт через GitHub Actions (`.github/workflows/pages.yml`).
